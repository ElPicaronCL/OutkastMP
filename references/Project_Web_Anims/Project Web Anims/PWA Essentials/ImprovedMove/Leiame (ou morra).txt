------- Instruções:

Extraia a pasta "ImprovedMove" para a pasta do Modloader.

-- Download da última versão do Modloader: MixMods.com.br/2015/01/SA-Modloader.html


 O mod inclui um arquivo .ini para configurar ao seu gosto.
 Por padrão diminui a velocidade de transição das animações, e modo de andar por padrão. Você pode querer desativar.
 Com o modo de andar, você pressiona o botão de correr pelo menos uma vez para começar a correr.
