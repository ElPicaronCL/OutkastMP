=======   MixMods.com.br   ======= - Best visualization with monospaced fonts, like "Consolas".


------- Instructions:

Extract the folder "Ped Run Fix" to your ModLoader folder.

-- Essentials Pack download: https://www.mixmods.com.br/2019/06/sa-essentials-pack/


 The mod replaces the file "data\animgrp.dat", having more than one in the modloader, merges it.
 If problems, and you have another animgrp.dat mod, mix them manually with some text editor and https://www.diffchecker.com/diff
