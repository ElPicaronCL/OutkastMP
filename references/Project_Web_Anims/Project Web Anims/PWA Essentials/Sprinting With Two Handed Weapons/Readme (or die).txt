------- Instructions:

Extract the folder "Sprinting With Two Handed Weapons" to your Modloader folder.

-- Download the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html



 Note: In the "Sprinting With Two Handed Weapons\anim" folder there is the original ped.ifp file of the game with only the new animation added: playersprint_armed
       If you want to add this animations to another .ifp, follow this tutorial: http://www.mixmods.com.br/2015/11/tutorial-trocar-animacoes-entre-ifps.html
 
 IMPORTANT: If crashes with this .asi, it was because you have an unadapted ped.ifp missing this animation!
            Adapt it with the tutorial above (the anim is in the end of the list) or make sure you are using this ped.ifp that came in the download and not another one that is also installed in another modloader folder.
 
 To work also with ripped and fat CJ, use the mod BeSlim: https://www.mixmods.com.br/2018/12/be-slim.html
