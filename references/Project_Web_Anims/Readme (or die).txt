------- Instructions:

Extract the folder "Project Web Anims" to your ModLoader folder.

Na pasta "(alt - PWA PEDs)" há algumas alternativas para a pasta "Project Web Anims\PWA PEDs". Por padrão o mod vem com "Remasterização".

-- Essentials Pack download: https://www.mixmods.com.br/2019/06/sa-essentials-pack/


== Mods included:
This pack already includes the mods in the "Project Web Anims\PWA Essentials" folder:
- ImprovedMove
- Open Door Anim
- Ped Run Fix
- Sprinting With Two Handed Weapons
If you already have one of these mods installed in your game, delete the mod folder in this mod so it doesn't get duplicated.

== IMPORTANT:
If you use another mod of "weapon.dat" or "default.ide" it may cause conflict with "PWA Essentials\PWA-Weapon.dat Real Weapon.dat" (crash when aiming with some weapons on certain occasions).
You might want to delete the folder of this mod or another.
If you use any other .ifp mod, you may want to increase the priority of this mod folder in modloader: https://www.mixmods.com.br/2015/07/tutorial-dicas-tudo-sobre-modloader-gta/#Priority
