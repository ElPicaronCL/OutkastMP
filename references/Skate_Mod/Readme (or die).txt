------- Instructions:

Extract the folder "Skate Mod" to your Modloader folder.
In the folder "(hq version)" there is a version with more defined textures, if you want, just put the files in the "Skate Mod" folder.

-- Download the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html
-- Needed Open Limit Adjuster: MixMods.com.br/2014/09/iiivcsa-open-limit-adjuster.html
-- Necessary fastman92 limit adjuster: MixMods.com.br/2015/09/fastman92-limit-adjuster.html



 IF YOU DON'T FOLLOW THE STEPS BELLOW THE GAME SOUND WILL STOP WORK OCCASIONALLY AND BIKES WILL BECOME BUGGED.
 The skateboard is added without replace, so here on download it already comes ready for add. If you want, see the full tutorial: https://www.mixmods.com.br/2015/12/tutorial-adicionar-carros-sem-substituir.html
            Download and install fastman92 limit adjuster: MixMods.com.br/2015/09/fastman92-limit-adjuster.html
            Open the "fastman92limitAdjuster_GTASA.ini" and find and configure the lines bellow.
              Put 1 at line "Apply handling.cfg patch"
              Increase at least +1 at line "Number of standard lines"
              Increase at least +1 at line "Number of bike lines"
              If you DON'T use Open Limit Adjuster: Increase at least +1 at line "Vehicle Models"
              DON'T FORGET THE REMOVE THE "#" AT START OF EACH LINE, IF NOT WILL NOT WORK.

 Commands: Take the cane (gun_cane, use weapon spawner or find pickups around SA) to get the skate (you can use some spawner), while with the skateboard in hand, press the stats button (TAB) to start walking with it.
           Basic control of a bike, no mysteries, in a short time you will understand the tricks.

 Replace the cane, if you want to add the weapon without replacing it, follow the tutorial: https://www.mixmods.com.br/2016/05/tutorial-adicionar-armas-sem-substituir.html
 then edit the .ini file of the mod by placing its ID (for example "WeaponID = 70")

 Detail: bikearmfix.asi is for fix bugged arms (stretched to hold properly on the bicycle handlebar, but it is no longer a bicycle, right?)
         Now CJ will hold the handlebars on Bike (bike.dff/txd) more lower than normal. Just download some BMX or Montain Bike mod and replace it with Bike: MixMods.com.br/2011/02/tutorial-substituir-qualquer-carro.html

 Problems: If some problem, maybe you have some other mod in Modloader that also replace these files. Remove it or check the .Priority tutorial: MixMods.com.br/2015/07/tutorial-dicas-tudo-sobre-mod-loader.html#priority
