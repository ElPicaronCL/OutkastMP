Expanded Peds & Gangs + Original Peds Vary Remaps for PedFuncs (For PC) 

Original pack created by Thanus Chan
Imported by Shadow Revenant to PC version

I did this because I was looking for a better expanded peds and gangs with more skins and I also found out this had PedFuncs variations, but it was made for mobile version. I decided to put this into the PC version, for people who play GTA San Andreas for PC version.

Mod features
• Restored beta/unused peds
• Restored beta/unused/introduction gangs
• New character models (SA Style)
• Added 108 new peds and gangs
• Added 324 remaps (only for OPV)

Installation:
Drag the files to modloader, but you need to do the following in the requirements first.

Requirements:
You need to install Pedfuncs & FastMan92 Limit Adjuster to increase Ped limits
You need PedFuncs installed to fix white hands & Original Peds Vary loader
You need to edit fastman92limitAdjuster_GTASA.ini config section "[IDE LIMITS] - ;Ped Models = 500. & ;Count of killable model IDs = 20000"
You need to add Extended Gang Wars for the Russian Mafia and Italian Mafia to appear on the streets.
Original Peds Vary is optional, if you want to see ped variations. (Please do install, it looks cool)

Used IDs #### 

Open peds.ide and scroll to "#---ADD NEW PEDS HERE"
The first one before the ped name is the IDs, you can change it to anything u want.
If you want to change it, see picture "IDS" and use some of it.
REMEMBER. if you have the same ids the game will crash, so if you have install some addon mods, make sure to check the ID to see if it use the same ID that i use for this mod, then change it. 

NOTE: This may be unstable, let me know if you receive crashes when you have this mod. Enjoy!
