------- Instructions:

Extract all inside the folder "(installation)" to your GTA SA directory.

-- Download the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html

You can also install everything in the ModLoader (except "_noDEP.asi", "cleo\Tuning Mod\PARTS" e "cleo\Tuning Mod\Vehicles"), but due to problems reports, first test the mod the way it came.
There are other languages in "(bonus)\(languages)".

Keep reading...



=== Installation principles ===
 Good GTA:               I recommend that you follow at least the first steps of this tutorial: https://www.mixmods.com.br/2014/11/primeiros-passos-para-montar-um-gta.html
 CLEO:                   It's required to use CLEO 4.3 or newer: https://www.mixmods.com.br/2014/02/Livraria-CLEO.html
 See more:               The mod contains several .ini files and you may want to set them to your liking.

-- If you have already installed an old very version of Tuning Mod (like v2):
 Delete the COMPLETELY mod before installing this new one, except the "EXTRAS" and "Vehicles" folders (where there are the settings of your parts and vehicles).
 The folder "CLEO\Tuning Mod\EXTRAS" is now called "CLEO\Tuning Mod\PARTS", if you just drag the files from the Tuning Mod v2 folder to this new one should work (but for a better alphabetical order, use "01" instead of "1" in the file name).


=== Usage principles ===
 It's working?           Holding the TAB key inside a car will pop up a stats bar, if it doesn't appear, the mod is not working, check everything.
 Getting Started:        Simply take a vehicle and go to the red mark in some garage for that vehicle (see "Local.jpg"). You have the option to type "TM555" (like a cheat) to call a tow to get you into the garage quickly.
 Entrance mark:          The red mark will only appear if you are inside the vehicle and it's the correct garage. For example the garage for bikes will only appear the red mark if you are on a bike.
 Mark doesn't appear:    If the mark doesn't appear anyway, it may be incompatible with some mod you have, but the mod can still work.
 Everything is black:    If you entered the garage and everything is black and you're using SkyGfx with Mobile colocycle, disable the colorcycle or open the "Tuning Mod - GRG.ini" and change the "WorldColor_Int" and "WorldColor_Ext" to other numbers, or turn it off by setting to "-1".
 How to use the mod:     Everything you need to know the mod tells you, seriously, everything is in the game interface, everything is on screen, read the screen!
 How to uninstall:       You can delete all mod files, but I DON'T recommend deleting "IndieVehicles.asi" and "_NoDEP.asi" as other mods may need them. If you saved the game with this mod installed, open the "Tuning Mod - CFG.ini" and read the description of "ShowRadarIcons".


=== Saving / loading vehicles ===
 No garages:             Conventional garages of the game don't support our cars, so...
 Commands:               Inside the vehicle, press the T+M keys to save it. To load a saved car, press T+L.
 Auto-save:              The mod has an auto-save system in case the game crashes at some point. Simply press B on the car loading screen to load the last car auto saved.
 How it works:           The mod uses .tmv extension files in which it only stores changes made. To have the car in full operation, it's necessary to have the correct parts and vehicles on which it was mounted. If you used an Elegy for example and then switched the Elegy to some Skyline, your vehicle will be loaded incompletely.
 Sharing:                To send your vehicles to other people, possibly you will have to also send the used parts and vehicles. Beware of the credits, respect the authors.
