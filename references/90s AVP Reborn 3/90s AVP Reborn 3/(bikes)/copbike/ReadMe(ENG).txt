Install:

To install dff and txd use IMGTool 2.0(or newer).
Open gta3.img with IMGTools (placed in models folderin catalog with game)
Find and delete copbike.dff è copbike.txd, then add copbike.dff, copbike.txd from this archive.


Open vehicles.ide ("data" folder) with Notepad, find and replace:

523,	copbike,	copbike,	bike,		HPV1000,	HPV1000,	wayfarer,	ignore,		10,	0,	0,		23, 0.75, 0.75,		-1

Open handling.cfg with same tool("Notepad") find and replace:

HPV1000 500.0     240.0 4.5 0.0 0.16 -0.001 103 1 0.78 0.5 3 210.0 50.0 15.0  R P  15.0 0.55 0 35.0 0.69 0.34 0.0 0.12 -0.11 0.5 0.0 0.0 0.15 10000 41002000 00300000 1 1 8


!   HPV1000     0.1     0.05    0.05    0.05    40.0    30.0    0.945   0.65    0.5     0.1     35.0    -40.0   -0.009  0.5     0.5


Next, install new colors in carcols.dat:

240,233,195            # 127 beeeje        light
