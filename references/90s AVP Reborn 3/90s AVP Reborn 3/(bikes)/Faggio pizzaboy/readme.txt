----------------------------------- Features ----------------------------------
-------------------------------------------------------------------------------


- V2 with huge materialfix, texturefix and small meshfixes
- 2 different Versions included (faggio and pizzaboy)
- High quality textures
- carcols with 2 colours
- SA lights
- SA license plates
- custom Coll and Shadow
- Highly detailed engine
- about 32000 polys (for each version)
- 1 extra (only faggio)


-------------------------------------------------------------------------------
--------------------------------- Installation --------------------------------
-------------------------------------------------------------------------------


First, open your gta3.img file with ImgTool and delete the original files
named "faggio.txd", "faggio.dff", "pizzaboy.txd", "pizzaboy.dff".

Then add the following files from the downloaded archive (with e.g. "IMGTool 2.0"):
"faggio.txd", "faggio.dff", "pizzaboy.txd", "pizzaboy.dff"

Now you have to edit the files "handling.cfg", "vehicles.ide" and "carcols.dat" 
with your notepad and replace the original lines with those:

handling.cfg:
MOPED         350.0     119.6   5.0    0.0 0.0  -0.2  103 2.0 0.9  0.49         3 160.0 30.0 65.0  R P   14.0  0.50 0 30.0       1.0  0.15  0.0   0.10 -0.07 0.5  0.0            0.1  0.001 10000        1000000		0			1  1	5

!	MOPED		0.45	0.55	0.25	0.15	43.0	30.0	0.89	0.75	0.8		0.1		40.0	-45.0	-0.010	0.7		0.6


vehicles.ide:
448,	pizzaboy,	pizzaboy,	bike,		MOPED,		PIZZABO,	bikev,		normal,		8,	1,	0,		16, 0.45, 0.45,		-1

462,	faggio,		faggio,		bike,		MOPED,		FAGGIO,		bikev,		moped,		10,	0,	0,		16, 0.45, 0.45,		-1


carcols.dat:

pizzaboy, 61,61, 66,66, 24,24, 123,123
