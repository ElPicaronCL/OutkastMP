------- Instructions:

Extract the folder "90s AVP Reborn 3" to your Modloader folder.

-- Download the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html

-- REQUIRED VehFuncs: MixMods.com.br/2018/01/VehFuncs.html
-- RECOMMENDED ImVehFt: MixMods.com.br/2020/01/IVF-Improved-Vehicle-Features.html
-- RECOMMENDED Open Limit Adjuster: MixMods.com.br/2014/09/iiivcsa-open-limit-adjuster.html


-- Tips:
For better body reflections:
MixMods.com.br/2019/12/SkyGfx.html

To increase the viewing distance of the low definition model (VehLODdist):
(MixSets and/or Open Limit Adjuster it is also required for the map not to fade and flick)
MixMods.com.br/2019/08/mod-mixsets.html

The mod works relatively well in SAMP. To really work as it should, use ModdedSAA (if the server allows it):
MixMods.com.br/2020/01/moddedsaa.html

For new license plates and dirt for ImVehFt, see the folder "ECG - Enhanced Classic Graphics - Vehicle".


-- Notes:
This pack already includes "ECG Vehicle.txd", "Wild Upgraded Your Cars 2" and "Lure Rancher".

In the folder ". (added without replace - adicionado sem substituir)" there are 2 cars added without replacing.
If you wish, remove the "." from the beginning of the name and configure the .ini of your fastman92 limit adjuster: MixMods.com.br/2015/12/tutorial-adicionar-carros-sem-substituir.html

The "WUYC (+ added tuning parts)" folder includes HD tuning parts, including parts added without replacing.
You have the option of not installing, but cars inside the "Need WUYC" folder need it.
If crash in 0x00534134 when starting the game, open the "veh_mods.ide" and check it: tuningmod.mixmods.com.br/p/incompatibilidade-entre-pecas.html

If you already have other cars, or want to install others with the pack, read the Priority section of the modloader tutorial:
https://www.mixmods.com.br/2015/07/tutorial-dicas-tudo-sobre-mod-loader.html#Priority
