PORTUGUESE:

O que é?
Uma versão do .cs sem marcar o trem no radar, o que algumas pessoas podem achar ruim ficar aparecendo no radar o marcador do trem chegando, então você tem a opção de substituir o .cs do mod por este sem o marcador no radar.

Como instalar?
Simplesmente coloque este arquivo .cs na pasta "Modloader\New Algorithm for Trains\CLEO\"

ENGLISH:

What is this?
A version of cs without marking the train on the radar, which some people may find it bad to be the marker on radar of the train coming, then you have the option of replacing the mod cs by this without the marker on the radar.

How to install?
Simply put this .cs in folder "Modloader\New Algorithm for Trains\CLEO\"
