------- Instructions:

Extract the "cleo" folder to any other folder inside Modloader. Or if you prefer to your GTA SA directory.
-- Download the lastest version of Mod Loader: MixMods.blogspot.com/2015/01/SA-Modloader.html

(Recommended to use CLEO 4.3 or newest)
-- Download the lastest version of CLEO: MixMods.blogspot.com/2014/02/Livraria-CLEO.html



 - Adapt weapons:   Open any folder function (cleo\EnhFuncs\***) and read the "How To Adapt.txt" - When edit the .cfg, save the file in ANSI encoding!!!
 - Special camera:  Type "enhcam1" or 2 or 3 | You can press "G" and then "Y" or "N" to up or down the speed of the game, nice to demonstrate your weapon in videos | The cameras and other things are configured in "cleo\EnhFuncs\Enh_config (weapons).ini"

 - The mod has come with the .cfg for the sawn-off, since the original game sawn-off is already adapted. You may experience problems in using a model "semi-adapted." If you have changed the model of the sawn-off and been buggy, delete or configure the file "CLEO\EnhFuncs\sawbarl\sawnoff.cfg"
