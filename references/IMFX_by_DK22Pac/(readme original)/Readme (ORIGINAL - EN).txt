### GTA SA Improved FX ###
    Test version 17.11.17

Plugin created by DK22Pac.
Effects creator - Function-X-.
Texture creators - Function-X- and oksa8.

IMFX - modification for GTA:SA which include:
-Lensflare v2.1 (sun flares)
-Moonphases v2.1 (moon phases)
-ProportionalCoronas (proportional coronas)
-ScreenWater (water drops on screen)
-Gunflash (improved gun flashes)
-Headshot (effect of head shots)
-Explosions (new explosions effects)
-Bloodspots (new blood effects)
-HD Roadsign (high quality roadsign font)

INSTALLATION
Delete modification's previous version (including plugin.dll) if it was installed.
Modification must be installed on GTA SA 1.0 US version. Modification requires .ASI-Loader to work.
Unpack imfx.asi file and imfx folder into scripts folder or folder where gta_sa.exe is placed.

This mod requires Overdose Effects version 1.5 (or higher):
http://www.gtagarage.com/mods/show.php?id=9226

Download latest version and updates here:
