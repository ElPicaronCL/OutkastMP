If you don't want to use some of the effects mod, it's recommended to disable "GUNFLASHES", "HEADSHOT" and "EXPLOSIONS" in "imfx.dat" as explained below.



= How to disable an effect?
If you don't like some effect, or are causing some conflict...
Open the file "imfx\imfx.dat" with some text editor.
It's self explanatory, there is the name of the effect, and a "YES"/"NO" after it saying "enabled" or "disabled". Edit and save the file.
