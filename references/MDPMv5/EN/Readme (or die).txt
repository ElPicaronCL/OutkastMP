------- Instructions:

Extract everything to your GTA SA folder. — You also have the option to install the "cleo" folder in "modloader\MDPM", except the "cleo\mdpm" folder.

-- Download of the latest version of Modloader: MixMods.com.br/2015/01/SA-Modloader.html
-- Required CLEO 4.3.23 or newer: MixMods.com.br/2014/02/Livraria-CLEO.html
-- If crash when opening the game: MixMods.com.br/2014/09/iiivcsa-open-limit-adjuster.html



== How to use:
Install songs in the "CLEO\MDPM" folder. In that folder there is a .txt file, read.
Inside a vehicle type "MDPM".
It's necessary to have speakers adapted to vibrate, but the mod works without them.
If you do not have cars adapted with speakers, follow the tutorial:: Forum.MixMods.com.br/f52-tutoriais/t13-mdpmv5-como-adaptar-aplicar-um-carro-para-vibrar
You can configure various things in the file "CLEO\MDPM.ini" and "MDPM - NPCs.ini".


== Important:
60 FPS is recommended for vibration to be realistic. 50~40 is acceptable.
If you have a monitor with more than 60 hz, for example 144 hz, use the mod in 144 FPS to be even more realistic.
You can use MixSets to adjust the FPS limit: MixMods.com.br/2015/12/mod-mix-sets.html
